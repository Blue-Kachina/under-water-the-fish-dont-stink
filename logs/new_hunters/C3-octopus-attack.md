2. Design decisions:
   - Style key "whip" (HunterAttack.STYLES + HunterBiteFx.SOUNDS need rows: shared files, returned in registrations).
   - Values read through WhipAttack.cfg(settings, key) with DEFAULTS + a `tune` override dict (works before registration; probes use tune).
   - Arms are driven by SHAPES (15 model-space joints per arm) -> Solver turns joints into per-segment (pitch,yaw,twist) bends via parallel-transport minimal rotations, plus optional per-segment bone stretch (skeleton.set_bone_pose_position) so a lash can reach beyond rest arm length.
   - Whip = cocked coil (direction-field spiral, coils tighter with charge, aimed at the lock) -> unrolling front base->tip lerps into a homing bezier (+travelling crack wave), tip arrives last and fast. Retract = reel-in front, ending at the rig's gait joints (provider) for no pop.
   - Judging: first (nearest) arm judged at the bite's contact tick via catch_rule (HunterBite landed feel = real hit/miss); the STRIKE phase is stalled (bite.t held) until that arm lands. Later arms judged per arrival through match.judge_drill (host only; same precedent as the Lamprey drill). Recoil applied per arm at arrival, summed and capped.
   - Net: puppets/guests run the same lock+timeline for visuals; host judges as drill does. net_catch_rule returns the host-side puppet's first arm.
